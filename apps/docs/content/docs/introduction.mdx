title: Introduction
description: Understand what Lunar ADK provides
---

Lunar ADK is a Bun-first, provider-neutral TypeScript runtime for building AI
agents. Applications compose models, agents, tools, workflows, sessions,
durable runs, and optional memory behind stable contracts.

Use `@lunar/adk` as the application-facing package. Provider and persistence
packages remain separate, so applications can select the model and storage
implementation that match their deployment.

Continue with [core concepts](/docs/core-concepts) or the
[getting started guide](/docs/guides/getting-started).
