description: Connect Lunar ADK to models, storage, memory, and telemetry

Available integrations include OpenAI and AI SDK model providers, SQLite,
Bun.SQL, HTTP, and MongoDB storage adapters, SQLite memory, and OpenTelemetry
exporters. See [models and providers](/docs/guides/models-and-providers),
[persistence](/docs/guides/persistence), and
[observability](/docs/observability).
