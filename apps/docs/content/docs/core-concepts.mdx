---
title: Core Concepts
description: Learn the runtime building blocks
---

- **Runtime** owns agent, workflow, event, storage, and memory registries.
- **Agent** combines a model provider, optional tools, and an execution policy.
- **Run** is the persisted record of one agent or workflow execution.
- **Session** groups related agent runs and conversation history.
- **Workflow** coordinates durable, code-first multi-step work.
- **Memory** is an optional provider-backed context store enabled per agent.

Read [agents and tools](/docs/guides/agents-and-tools),
[runs and sessions](/docs/guides/runs-and-sessions), and
[workflows](/docs/guides/workflows) for the complete model.
