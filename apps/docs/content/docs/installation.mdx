---
title: Installation
description: Add Lunar ADK packages to a Bun project
---

Install the stable SDK facade in an existing Bun and TypeScript project:

```bash
bun add @lunar/adk
```

Install only the adapters your application uses. For example, an OpenAI-backed
agent needs:

```bash
bun add @lunar/provider-openai
```

See [models and providers](/docs/guides/models-and-providers) for adapter setup.
