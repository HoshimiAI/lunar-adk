---
title: Architecture
description: See how Lunar ADK separates runtime contracts from adapters
---

Lunar Foundation defines the runtime contracts for agents, models, tools,
workflows, events, storage, and memory. `@lunar/adk` is the stable facade for
applications. Provider, storage, memory, and observability packages implement
those contracts without coupling the runtime to a vendor or database.

The runtime uses in-memory stores by default. Applications can pass a storage
bundle and memory provider to `createRuntime()` when durability is required.
Read the [Foundation reference](/docs/reference/foundation) and
[adapter reference](/docs/reference/adapters) for public contracts.
