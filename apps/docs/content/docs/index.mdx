Lunar ADK is a Bun-first, provider-neutral TypeScript runtime for building AI
agents. Applications compose models, agents, tools, workflows, sessions,
durable runs, memory, observability, and optional external adapters behind
stable contracts.

advanced integrations, then add only the model, storage, memory, auth, or
telemetry adapter packages your deployment needs.
